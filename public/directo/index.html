Sin dar nada por sabido

Claude Code no es un chat: trabaja dentro de tu carpeta

En el chat copias y pegas. Claude Code lee, crea y cambia los archivos de tu proyecto mientras tú le hablas en español. Tú decides qué hacer; él escribe el código.

  • Claude.ai · pensar, escribir, investigar
  • Claude Code · construir: webs, apps, automatizaciones
  • Comparación: «el chat te da la receta; Claude Code cocina en tu cocina».
  • Necesitas un plan de pago de Claude para usarlo con soltura: dilo claro, sin vender nada.
Pasos 1, 2 y 3 · en directo

Monta tu taller en 5 minutos

  1. Crea una carpeta en el Escritorio: mi-primera-web
  2. Instala VS Code (gratis) y abre la carpeta: Archivo → Abrir carpeta.
  3. Instala la extensión Claude Code desde Extensiones y entra con tu cuenta.
  • Hazlo de verdad en pantalla, despacio. Sin atajos de teclado raros.
  • En Windows: clic derecho en el Escritorio → Nuevo → Carpeta.
  • Pregunta en el chat: «¿quién ya tiene VS Code abierto?».
Paso 4 · copia este prompt

Le pedimos una web para un negocio de verdad

Crea una web de una sola página para «Peluquería Lola», en L'Hospitalet de Llobregat. Público: vecinos del barrio que la buscan en el móvil. Secciones: portada con un botón de WhatsApp, servicios con precios, horario, cómo llegar y opiniones. Estilo: cálido y moderno, que se vea perfecta en el móvil. Todo en un solo archivo index.html, sin instalar nada.

Cambia «Peluquería Lola» por un negocio de tu calle.

  • Pega el prompt en Claude Code y lee en voz alta lo que va haciendo.
  • Explica cada parte: quién es el público, qué secciones, qué estilo.
  • Si algo sale raro, corrígelo hablando: «el botón de WhatsApp más grande».
Paso 5

Ábrela en el navegador y pide cambios

Doble clic en index.html. Ya tienes una web. Ahora la mejoras hablando: «pon fotos del local», «añade un mapa», «haz el título más grande».

  • Haz 2 o 3 cambios en directo pedidos por el chat.
  • Enséñala en modo móvil (F12 → icono del móvil).
Pasos 6 y 7

De tu ordenador a internet

  1. GitHub: guarda tu proyecto en la nube, con historial. Gratis.
  2. Cloudflare: conecta el repositorio y tu web sale con su dirección. Gratis para empezar.
  3. Cada cambio que subes se publica solo.
  • Pídele a Claude Code: «súbelo a un repositorio nuevo de GitHub».
  • En Cloudflare: Workers y Pages → Crear → Importar repositorio.
  • Enseña la dirección final en el móvil: es el momento «wow».
